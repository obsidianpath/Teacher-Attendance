# Журнал посещаемости для учителя

Веб-приложение для учёта посещаемости учеников по школам и классам с автоматическим подсчётом заработанной суммы и формированием отчётов.

## Стек

- Чистый HTML + CSS + JavaScript (ES-модули)
- Supabase (PostgreSQL + Auth + RLS)
- Хостинг: GitHub Pages

## Возможности

- Регистрация и вход учителя (email + пароль)
- Каждый учитель видит только свои данные (изоляция через RLS)
- Школы → классы → ученики (с ФИО родителя и телефоном)
- Журнал: отметки по датам (зелёный — присутствует, красный — отсутствует)
- Автоматический подсчёт суммы за урок и за всё время
- Отчёты за неделю / месяц / произвольный период
- Экспорт в CSV и печать
- 5 тем оформления (светлая, тёмная, синяя, зелёная, тёплая)
- Полная адаптивность (работает на телефоне)
